Contrato del MVP

  • Pool persistente por sesión: al iniciar Pi, la extensión levanta el equipo configurado.
  • Subagente real: proceso Pi separado, no una llamada LLM dentro del principal.
  • Comunicación: JSONL/RPC sobre stdio como primera opción; filesystem solo para logs/transcript y recuperación.
  • Modo estricto: el principal recibe instrucciones de sistema y tools para delegar trabajo significativo al pool.
  • Widget vivo: busy = color activo/animado; idle = color tenue; dead/error = rojo/gris.

Módulos

  • extensions/full-subagents.ts: registro de extensión, comandos, tools, lifecycle.
  • extensions/lib/full-subagents-com.ts: protocolo, subprocess manager, mensajes, restart/cancel.
  • extensions/lib/full-subagents-widget.ts: render de tarjetas y footer/status.
  • extensions/lib/full-subagents-config.ts: merge/validación de orgm.json.fullSubagents.
